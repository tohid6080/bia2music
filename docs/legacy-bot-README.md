# AI Music Manager — Bia2Music (نسخه ۱٫۰)

ربات تلگرامی فارسی برای مدیریت، رشد و درآمدزایی کانال [Bia2Music](https://t.me/bia2music1395) که کاملاً با گوشی اندرویدی مدیریت می‌شود.
هیچ سرویس پولی اجباری نیست. **هیچ پستی بدون تأیید صریح شما در کانال منتشر نمی‌شود** (آهنگ و تبلیغ: پیش‌نمایش ← تأیید ← تأیید نهایی).

## 📈 رشد و توسعه کانال (مرحله ۶ ✅)
**مسیر:** منوی اصلی ← 📈 رشد و توسعه کانال.
- **کمپین‌ها:** برای هر منبع (اینستاگرام، واتساپ، دوستان، کانال همکار، گروه‌های موسیقی، تبلیغات، سایر) یک **لینک دعوت اختصاصی** با نام کمپین (`createChatInviteLink`) ساخته می‌شود. 🔳 QR کد (فقط به چت شما)، 📋 لینک برای کپی، 🚫 ابطال (با تأیید)، 🗑 حذف کمپین ابطال‌شده (آمارش به «نامشخص» منتقل می‌شود).
- **شمارش عضویت:** از رویداد `chat_member` تلگرام (ربات ادمین با حق **Invite Users**). منبع عضویت از `invite_link` رویداد ثبت می‌شود؛ ورود بدون لینک «نامشخص/ارگانیک» است.
- **گزارش:** اعضای فعلی، رشد امروز/هفته/ماه، ورود و خروج روزانه (UTC)، عضو هر کمپین، بهترین کمپین و منبع، نمودار.
- **صداقت داده:** تعداد **کلیک** لینک را تلگرام به ربات‌ها نمی‌دهد و هرگز «۰» یا تخمینی نشان داده نمی‌شود؛ فقط عضویت‌های تأییدشده شمرده می‌شود. اگر رویدادی نیامده باشد «در دسترس نیست» نوشته می‌شود. **برای کانال‌ها، دریافت رویداد `chat_member` باید عملاً آزمایش شود:** 🧪 وضعیت دریافت رویداد عضویت، وضعیت را نشان می‌دهد و راهنمای آزمون دارد.
- **حریم خصوصی:** فقط شمارنده‌ی روزانه ذخیره می‌شود؛ نام، نام‌کاربری یا شناسه‌ی عضو هرگز. گزینه‌ی 🔐 (پیش‌فرض خاموش) فقط یک هش نمکی یک‌طرفه برای نسبت‌دادن «خروج» به کمپین نگه می‌دارد و با خروج همان عضو پاک می‌شود.
- **ممنوع و ممکن‌نشده:** عضو فیک، عضویت اجباری، افزودن بدون رضایت، پیام انبوه. تست خودکار وجود هیچ‌یک از این ابزارها را در کد رد می‌کند.
- QR به بسته‌ی اختیاری `segno` نیاز دارد (`pip install segno`)؛ نبودنش ربات را متوقف نمی‌کند و لینک متنی می‌دهد.

## 📝 متن‌های تبلیغ، 🗓 برنامه‌ی هفتگی، 🏁 نقاط عطف (مرحله ۷ ✅)
**مسیر:** 📈 رشد و توسعه کانال ← «📝 متن‌های تبلیغ» / «🗓 برنامه‌ی هفتگی» / «🏁 نقاط عطف».
- **متن تبلیغ (رایگان، بدون AI):** واتساپ، اینستاگرام، تلگرام، همکاری با کانال‌ها، پیام کوتاه دعوت، معرفی آهنگ‌های محبوب؛ هرکدام ۳ نسخه. لینک کانال یا **لینک اختصاصی یک کمپین** در متن درج می‌شود (برای ردیابی عضویت). متن داخل بلوک کپی (`<code>`) است: یک لمس = کپی. ✏️ ویرایش، 🔄 نسخه‌ی دیگر (اگر ویرایش کرده باشید قبلش می‌پرسد)، 🗑 حذف.
- **فقط داده‌ی واقعی:** تعداد آهنگ (از ۵ به بالا)، تازه‌ترین یا پرپسندترین آهنگ‌های آرشیو؛ اگر داده نباشد آن خط نمی‌آید و عددی ساخته نمی‌شود. «محبوب‌ترین» فقط وقتی نوشته می‌شود که پسند واقعی باشد وگرنه «تازه‌ترین». ربات هیچ‌یک را خودش منتشر یا ارسال نمی‌کند؛ شما کپی می‌کنید (و قوانین هر گروه/شبکه را رعایت می‌کنید).
- **برنامه‌ی هفتگی (قانون‌محور، نه AI):** وضعیت و مرحله، نوع موسیقی (از علایق/پسند/ترکیب آرشیو)، تعداد پست، **سه آزمایش** روز/ساعت (نه «بهترین زمان»)، موضوع نظرسنجی، معیار کانال همکار، محتوای اشتراک‌پذیر؛ هر بخش پایه‌ی داده‌اش را می‌گوید و داده‌ی ناموجود را «در دسترس نیست» می‌نویسد. هیچ ادعای قطعی درباره‌ی افزایش اعضا ندارد. هر شنبه بعد از ساعت ۹ خودکار به چت شما می‌آید (قابل خاموش‌کردن) و بر اساس آمار امروز دوباره تولید می‌شود.
- **نقاط عطف:** ۲۲ / ۱۰۰ / ۵۰۰ / ۱۰۰۰ (قابل افزودن، ویرایش و حذف؛ حداقل یکی می‌ماند). رسیدن به هر نقطه فقط **یک پیام** به شما می‌دهد (اولین اجرا نقاط قبلی را بی‌صدا ثبت می‌کند) و عمق پیشنهادهای برنامه را بالا می‌برد. **هیچ انتشار خودکاری فعال نمی‌شود**؛ تست ساختاری تضمین می‌کند این ماژول‌ها اصلاً قابلیت ارسال/انتشار ندارند.

## 🔥 رادار موسیقی‌های ترند (مرحله ۸ ✅: هسته و منابع)
**مسیر:** منوی اصلی ← 🔥 رادار موسیقی‌های ترند. از همان ابتدا فعال است، ولی **هیچ منبعی بدون تأیید صریح شما فعال نمی‌شود.**
- **منابع API (پیش‌فرض خاموش؛ با تأیید دوم و خواندن شرایط):**
  - **YouTube Trending Music** (API رسمی Data v3، `videos.list` با `chart=mostPopular` و دسته‌ی موسیقی؛ کلید رایگان `YOUTUBE_API_KEY`؛ ۱ واحد از ۱۰٬۰۰۰ واحد روزانه برای هر منطقه؛ سقف روزانه‌ی ربات ۱۵۰ درخواست).
  - **Last.fm** (`chart.getTopTracks` جهانی و `geo.getTopTracks` کشوری؛ کلید رایگان `LASTFM_API_KEY`).
  - **Deezer Chart** و **Apple Music Most Played** (فید رسمی؛ بدون کلید؛ شامل تاریخ انتشار از طرف خود Apple).
  - مناطق هر منبع قابل ویرایش است (مثلاً US,GB,TR).
- **منابع فقط‌لینک (بدون اسکرپ):** FarsiChart، Radio Javan، YouTube Music/Shorts Charts، Spotify Charts، Shazam Charts. برای هرکدام لینک صفحه و شرایط، و برای تصمیم‌گیری شما دکمه‌ی «🧪 بررسی robots.txt» (فقط اطلاع؛ هیچ صفحه‌ای از سایت دریافت نمی‌شود) هست. آهنگ‌های دیده‌شده را «✍️ ثبت دستی» کنید (فقط عنوان/خواننده/لینک؛ رتبه و آمار ساخته نمی‌شود).
- **کش و محدودیت:** هر منبع TTL (۶ تا ۱۲ ساعت) و حداقل فاصله‌ی درخواست دارد؛ نمودار کهنه (بیش از ۳ برابر TTL) با «⚠️ به‌روز نیست» علامت می‌خورد و در امتیاز نمی‌آید؛ شکست یک منبع/منطقه بقیه را متوقف نمی‌کند و داده‌ی سالم قبلی را پاک نمی‌کند؛ ۱۰ عکس آخر هر نمودار نگه داشته می‌شود. به‌روزرسانی دوره‌ای خودکار فقط برای منابع فعال‌شده توسط شماست و چیزی منتشر یا ارسال نمی‌کند.
- **نمایش:** «📋 نمودار هر منبع»: رتبه و شاخص اصلی خود منبع، تغییر رتبه (▲▼＝، «🆕 تازه وارد»، یا «نامشخص» اگر عکس قبلی نیست)، تاریخ انتشار فقط اگر منبع داده، لینک منبع، و زمان آخرین به‌روزرسانی.
- **🔥 ترندهای ترکیبی:** «امتیاز ربات» (جدا از شاخص رسمی منابع) با فرمول شفاف: (۲۶−رتبه) + تغییر رتبه (−۵ تا +۱۰) + ۱۰ برای هر منبع مستقل اضافه + تازگی (فقط با تاریخ خود منبع). وزن‌ها در «📐 روش محاسبه» قابل تغییر است. تعداد پخش کل معیار نیست. تطبیق بین منابع با نام خواننده/عنوان **تقریبی** است.
- **هیچ فایلی دانلود یا منتشر نمی‌شود**؛ فقط متادیتا و لینک رسمی. تست ساختاری: ماژول‌های رادار نمی‌توانند پیام/فایل بفرستند، دانلود کنند یا منتشر کنند، و فقط به ۴ میزبان API فهرست‌شده درخواست می‌روند. کلیدها هرگز در دیتابیس، پیام یا لاگ نمی‌آیند.
- **محدودیت صادقانه:** آدرس/ساختار پاسخ این APIها را با داده‌ی واقعی **آزمایش نکرده‌ام** (این محیط به آن‌ها دسترسی ندارد)؛ تجزیه‌گرها دفاعی‌اند و اگر ساختار را نفهمند «ساختار پاسخ منبع شناخته نشد» می‌دهند. بعد از فعال‌سازی، «🧪 دریافت/آزمایش اکنون» را بزنید. برای موسیقی **ایرانی** API رسمی مطمئنی نمی‌شناسم؛ بخش ایرانی فعلاً لینک + ثبت دستی است.
- **مرحله ۹ (بعدی):** گروه‌بندی و فیلترها، دکمه‌های ⭐/📚/📝/🔎/✅/❌ برای هر پیشنهاد، تکراری‌نشدن با آرشیو، وضعیت مجوز و گزارش روزانه.

## 🎯 از رادار تا انتشار (مرحله ۹ ✅)
در «🔥 رادار» هم‌اکنون: گروه‌ها (🔥 ترند امروز، 🇮🇷 ایرانی، 🌍 خارجی، 🆕 تازه، 📈 رشد سریع، ⭐ ذخیره‌شده‌ها، 🚫 ردشده‌ها، 🎧 بر اساس سبک، 🎤 خواننده‌های محبوب) و **فیلترها** (ایرانی/خارجی، کشور نمودار، سبک، زبان، بازه‌ی انتشار، تازه/ترند، محبوبیت، رشد) با دکمه.
- هر پیشنهاد یک **کارت** دارد: ⭐ ذخیره · 📚 افزودن به آرشیو · 📝 آماده‌سازی کپشن · 🔎 منبع اصلی · ✅ افزودن به پیش‌نویس انتشار · ❌ رد · 🔁 ایرانی/خارجی · 🔏 ثبت مجوز.
- آهنگ‌های موجود در آرشیو و ردشده‌ها **دوباره پیشنهاد نمی‌شوند**.
- «افزودن به آرشیو/پیش‌نویس» فقط یک آهنگ **بدون فایل** می‌سازد؛ وقتی خودتان فایل را (با مجوز) بفرستید، به همان آهنگ وصل می‌شود.
- وضعیت مجوز هر پیشنهاد: «نامشخص» / «فقط لینک رسمی منبع» / «ثبت‌شده توسط مدیر». ربات هیچ فایلی دانلود یا منتشر نمی‌کند و هیچ‌چیز بدون تأیید شما منتشر نمی‌شود.
- **گزارش روزانه** (پیش‌فرض خاموش): در «🔥 رادار ← 🛠 ابزارها ← 📬 گزارش روزانه» روشن و ساعتش را تنظیم کنید؛ فقط به چت مدیر می‌رود و خطای منبع‌ها را هم می‌گوید.
- ایرانی/خارجی و زبان **تقریبی** (از روی خط نوشتار) و قابل اصلاح دستی‌اند.

## 📌 دکمه‌ی ربات زیر پست‌های قدیمی کانال
«⚙️ تنظیمات ← دکمه‌ی ربات روی پست‌های قدیمی»: همان دکمه‌ی زیر پست را روی آهنگ‌های قبلی کانال هم می‌گذارد (فقط `editMessageReplyMarkup`؛ متن و فایل دست نمی‌خورد). ابتدا روی ۱ پست آزمایش می‌شود، سپس با تأیید دومرحله‌ای ادامه می‌دهد، قابل توقف/ازسرگیری و قابل حذف است. محدودیت‌ها: دکمه‌های قبلیِ آن پست جایگزین می‌شوند، ربات باید دسترسی «ویرایش پیام‌های دیگران» داشته باشد، و «معرفی ربات» (فوتر) روی پست‌های قدیمی اعمال نمی‌شود چون بازنویسی کپشن قالب‌بندی را از بین می‌برد.

## 🧭 استراتژی محتوا و رشد (مرحله ۱۰ ✅)
مسیر: 📈 رشد ← 🗓 برنامه‌ی هفتگی ← 🧭 استراتژی محتوا. نقطه‌ی عطف فعلی، روند واقعی اعضا، علایق مخاطبان، آماده‌های آرشیو و پیشنهادهای رادار را کنار هم می‌گذارد: تمرکز مرحله، ۳ پیشنهاد رادار سازگار با علایق، کمبود آهنگ آماده، پیش‌نویس‌های بدون فایل، و ارتباط ورود/خروج و بهترین کمپین با محتوا. فقط پیشنهاد متنی است؛ چیزی منتشر یا ارسال نمی‌شود و داده‌ی ناموجود «در دسترس نیست» نوشته می‌شود.

```
musicbot/

  auth.py           کنترل دسترسی (فقط ADMIN_USER_ID، فقط چت خصوصی)
  channel.py        اتصال فقط‌خواندنی به کانال (getChat / getChatMember)
  context.py        اشیای مشترک برنامه
  logging_setup.py  لاگ فایل + پنهان‌سازی خودکار توکن
  db/               schema.py (جدول‌ها)، database.py، repositories.py
  ai/               base.py (رابط‌ها)، factory.py (انتخاب Provider)، rule_based.py (قالب و قوانین)
  publishing/       captions.py، service.py (تنها جای ارسال به تلگرام)، scheduler.py (فقط یادآوری)، timeutil.py، jalali.py
  songs/            service.py (دریافت فایل و تشخیص تکراری)، textutils.py (نرمال‌سازی فارسی)
  recommend.py      پیشنهاد آهنگ (امتیازدهی شفاف، بدون AI)
  handlers/         users.py (کاربران عادی)، admin_users.py، playlists.py، menu.py، songs.py (کارت/ویرایش)، archive.py (فهرست/جست‌وجو)، settings.py، ai_status.py، errors.py، common.py
  ui/               texts.py (متن فارسی)، keyboards.py (دکمه‌ها)
tests/              تست‌های pytest
.env.example        نمونه تنظیمات (بدون راز)
```
جدول‌ها: admins, users, songs, genres, moods, publication_queue, channel_settings, playlists, activity_logs, ai_settings
(+ languages و playlist_songs). دیتابیس اجازه نمی‌دهد وضعیت «منتشرشده» بدون ثبت تأیید مدیر ذخیره شود.

## راه‌اندازی (روی کامپیوتر، یک‌بار)
```bash
cd ai-music-manager
python3 -m venv .venv
source .venv/bin/activate          # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # سپس .env را ویرایش کنید
python -m musicbot
```
در `.env` باید حداقل `TELEGRAM_BOT_TOKEN` و `ADMIN_USER_ID` را پر کنید. فایل `.env` هرگز وارد Git نمی‌شود.

## ساخت ربات با BotFather
1. در تلگرام `@BotFather` را باز کنید (تیک آبی دارد).
2. دستور `/newbot` را بفرستید.
3. یک نام نمایشی (مثلاً `Bia2Music Manager`) و سپس نام کاربری که به `bot` ختم شود (مثلاً `bia2music_manager_bot`) بدهید.
4. BotFather یک **توکن** می‌دهد (شبیه `123456:ABC...`). آن را فقط در `.env` بگذارید و برای کسی نفرستید.
   اگر لو رفت: `/revoke` در BotFather.

## پیدا کردن شناسه عددی تلگرام
در تلگرام به `@userinfobot` پیام بدهید؛ عدد `Id` را در `ADMIN_USER_ID` بگذارید.

## اتصال ربات به کانال Bia2Music
1. کانال را باز کنید ← نام کانال (بالا) ← **Administrators** ← **Add Administrator**.
2. نام کاربری ربات خود را جستجو و انتخاب کنید.
3. دسترسی **Post Messages** را روشن کنید (بقیه لازم نیست) و تأیید کنید.
4. در ربات: ⚙️ تنظیمات ← 📡 وضعیت اتصال به کانال. باید «ربات ادمین است ✅» و «اجازه ارسال دارد ✅» ببینید.
- مقدار پیش‌فرض `CHANNEL_ID=@bia2music1395` است. برای تغییر کانال: ⚙️ تنظیمات ← ✏️ تغییر کانال مقصد (بدون تغییر کد).

## استفاده با گوشی اندرویدی
فقط ربات را در تلگرام موبایل باز کنید و `/start` بزنید. همه‌چیز با دکمه است:
- **⚙️ تنظیمات**: وضعیت کانال، تغییر کانال مقصد (با پیش‌نمایش و تأیید)، گزارش فعالیت‌ها
- **🤖 وضعیت هوش مصنوعی**: نشان می‌دهد AI واقعی فعال است یا نه
- **❓ راهنما**
- بقیه بخش‌ها پیام «این قابلیت در مرحله بعدی فعال خواهد شد» می‌دهند.
هر صفحه دکمه بازگشت/لغو دارد و `/cancel` عملیات جاری را لغو می‌کند.

## امکانات مرحله ۲
| فعال ✅ | غیرفعال 🚧 (مراحل بعد) |
|---|---|
| دریافت فایل صوتی (آپلود یا فوروارد) و ساخت پیش‌نویس خودکار | کپشن/هشتگ در پنل، پیش‌نمایش، انتشار، زمان‌بندی (مرحله ۳) |
| خواندن نام/خواننده از برچسب فایل یا نام فایل | کاربران، پیشنهاد، پلی‌لیست (مرحله ۴) |
| ویرایش نام، خواننده، زبان، سبک، حال‌وهوا | آمار، تبلیغات، درآمدزایی (مرحله ۵) |
| تشخیص تکراری با File Unique ID و هش SHA-256 (فایل تا ۲۰ مگابایت) و هشدار آهنگ مشابه | شناسایی آهنگ از روی صدا (سرویس تخصصی، آینده) |

| تنظیمات کانال، وضعیت AI، گزارش فعالیت‌ها | |

**نحوه کار:** ربات را باز کنید ← فایل صوتی را برایش بفرستید ← کارت آهنگ می‌آید ← با دکمه‌ها اطلاعات را کامل کنید ← «✅ ثبت در آرشیو».
برای ثبت نهایی، نام آهنگ، خواننده و زبان لازم است. هیچ‌چیز در کانال منتشر نمی‌شود.

**به‌روزرسانی از مرحله ۱:** فایل‌های جدید را جایگزین کنید (`.env` و پوشه `data/` را دست نزنید) و ربات را دوباره اجرا کنید؛ دیتابیس خودکار به نسخه ۲ ارتقا می‌یابد.

## انتشار (مرحله ۳)
**مسیر:** آهنگ ثبت‌شده در آرشیو ← «📤 پیش‌نمایش و انتشار» ← پیام صوتی پیش‌نمایش (فقط برای شما، دقیقاً همان‌چیزی که منتشر می‌شود) ← «✅ تأیید و انتشار» ← «✅ بله، همین حالا منتشر شود» ← ارسال به کانال.

**قفل‌های ایمنی**
- دو تأیید صریح پشت‌سرهم لازم است.
- انتشار به «اثر انگشت» پیش‌نمایش گره خورده است: اگر بعد از پیش‌نمایش کپشن/هشتگ/نام عوض شود، دکمه‌های قدیمی رد می‌شوند و باید پیش‌نمایش جدید بگیرید.
- زمان‌بندی **انتشار خودکار نمی‌کند**: وقتی زمان می‌رسد فقط یادآوری می‌گیرید و باید دوباره پیش‌نمایش و تأیید کنید. (اگر در آینده انتشار خودکار پیش‌تأییدشده بخواهید، باید صریحاً درخواست دهید.)
- ضربه‌ی دوم یا همزمان، پست تکراری نمی‌سازد (قفل اتمیک در دیتابیس) و دیتابیس وضعیت «منتشرشده» را بدون ثبت تأییدکننده و زمان تأیید نمی‌پذیرد.
- اگر هنگام ارسال اینترنت قطع شود و معلوم نباشد پست رفته یا نه، آهنگ در وضعیت «در حال انتشار» می‌ماند تا کانال را بررسی کنید؛ بعد از کارت آهنگ دکمه‌ی بازگشت به «آماده» هست.
- تست‌های خودکار ساختاری تضمین می‌کنند فقط یک تابع (`_go`) اجازه‌ی انتشار دارد و زمان‌بند به آن دسترسی ندارد.

**کپشن و هشتگ:** با قالب و قوانین ساخته می‌شود (هوش مصنوعی واقعی نیست) و قابل ویرایش/تولید دوباره است. سقف کپشن+هشتگ ۱۰۲۴ حرف.

**زمان‌بندی:** دکمه‌های سریع (۱ ساعت دیگر، امشب ۲۱:۰۰، فردا ۱۰:۰۰ و ...) یا زمان دلخواه: `21:30`، `1405/08/20 21:30` (شمسی)، `2026-11-10 21:30`. ربات باید روشن باشد تا یادآوری بفرستد؛ اگر خاموش بود، با روشن‌شدن یادآوری‌های عقب‌مانده را می‌فرستد.

## امکانات کاربران (مرحله ۴)
**پیش‌فرض خاموش است.** مدیر در ⚙️ تنظیمات ← «👥 امکانات کاربران» آن را روشن می‌کند (با تأیید)؛ هر زمان می‌تواند خاموشش کند. تا وقتی خاموش است، غیرمدیرها فقط پیام «مخصوص مدیر» می‌بینند. مدیر همیشه می‌تواند با «👥 مدیریت کاربران ← 👤 نمای کاربر» آن را امتحان کند.

**برای کاربران (وقتی روشن باشد):**
- 🔍 جست‌وجو: کافی است نام آهنگ یا خواننده را بنویسند (مستقل از ی/ي و ک/ك).
- 💡 پیشنهاد: بر اساس علایقی که خودشان انتخاب کرده‌اند (و پسندها)؛ بدون علایق، ترکیب محبوب‌ها و تازه‌ها. «پیشنهاد دیگر» تکراری نمی‌دهد.
- 🎭/🌐 مرور بر اساس حال‌وهوا و زبان، 🎧 پلی‌لیست‌ها، ❤️ پسند، 🎤 درخواست آهنگ (حداکثر ۳ در روز، به مدیر اطلاع داده می‌شود).
- فقط آهنگ‌های **منتشرشده** دیده می‌شود و فایل ارسال نمی‌شود؛ دکمه «شنیدن در کانال» لینک پست را می‌دهد.

**حریم خصوصی:**
- جست‌وجو و مرور بدون ذخیره‌ی چیزی جز شناسه/نام کاربری تلگرام (برای مدیریت و مسدودسازی) است.
- علایق و پسندها **فقط با رضایت صریح** و فقط همان چیزی که خود کاربر انتخاب می‌کند ذخیره می‌شود (ربات چیزی حدس نمی‌زند). بدون رضایت، دیتابیس حتی اجازه‌ی ثبت آن‌ها را نمی‌دهد.
- «🗑 حذف اطلاعات من» علایق، پسندها، درخواست‌ها و رضایت را پاک و نام کاربری/نام را خالی می‌کند.
- مدیر فقط آمار **تجمیعی** علایق را می‌بیند (بدون هویت).

**برای مدیر:**
- 👥 مدیریت کاربران: آمار، کاربران اخیر، مسدود/رفع مسدودی، علایق تجمیعی، صف درخواست‌ها.
- 🎧 پلی‌لیست‌ها: ساخت، تغییر نام، افزودن/حذف آهنگ (همچنین از کارت آهنگ)، حذف با تأیید. کاربران فقط آهنگ‌های منتشرشده‌ی هر پلی‌لیست را می‌بینند.
- 💡 پیشنهاد آهنگ: کدام آهنگ آماده را منتشر کنم؟ مرتب‌شده بر اساس علایق تجمیعی مخاطبان + محبوب‌ترین‌ها.

**محدودیت‌ها:** ربات برای هر کاربر فقط در چت خصوصی کار می‌کند. محدودیت نرخ پیام‌ها فقط برای «درخواست آهنگ» است. پیشنهاد، آهنگ‌های منتشرشده را در حافظه امتیاز می‌دهد (برای چند هزار آهنگ مناسب است).

## معرفی ربات در پست‌های کانال
در ⚙️ تنظیمات دو کلید هست: «🔗 دکمه‌ی ربات زیر پست» (پیش‌فرض روشن) و «🤖 خط ربات در کپشن» (پیش‌فرض خاموش). هر دو در پیش‌نمایش دیده می‌شوند و جزو اثر انگشت انتشارند؛ یعنی پستِ منتشرشده دقیقاً همان پیش‌نمایش است و با عوض‌کردن کلیدها پیش‌نمایش قدیمی رد می‌شود. دکمه‌های کنترلی مدیر هرگز در کانال نمی‌رود.

## درون‌ریزی آهنگ‌های قدیمی کانال
**مسیر:** 📚 آرشیو ← 📥 درون‌ریزی از کانال.

**چطور کار می‌کند:** ربات‌ها تاریخچه‌ی کانال را نمی‌خوانند، اما ربات ادمین کانال می‌تواند هر پست را با شماره‌اش فوروارد کند. ربات از پست ۱ تا آخرین پست را یکی‌یکی به **چت خصوصی خودتان** فوروارد می‌کند (بی‌صدا)، نام/خواننده/فایل/کپشن را می‌خواند و پیام موقت را فوراً پاک می‌کند. چیزی در کانال منتشر یا تغییر نمی‌کند (تست ساختاری: فوروارد فقط در `importer.py` و مقصد فقط چت مدیر).

**مراحل:**
1. ربات باید در کانال ادمین باشد.
2. در کانال آخرین پست را باز کنید ← روی آن نگه دارید ← Copy Link ← لینک را به ربات بفرستید (یا فقط شماره‌ی آخر لینک).
3. اول «🧪 آزمایش ۲۰ پست آخر» را بزنید و نتیجه را ببینید.
4. اگر درست بود، «▶️ درون‌ریزی کامل» را بزنید و تأیید کنید. حدود ۱٫۲ ثانیه برای هر پست؛ ۲۵۰۰ پست ≈ ۵۰ دقیقه. Termux باید باز بماند. با «⏹ توقف» می‌ایستد و بعداً از همان‌جا ادامه می‌دهد.

**نتیجه:** آهنگ‌ها با وضعیت «منتشرشده» و لینک پست خودشان ثبت می‌شوند؛ کاربران با جست‌وجو و «🎧 شنیدن در کانال» به همان پست می‌رسند. فایل تکراری (همان File Unique ID) دوباره ثبت نمی‌شود و آهنگی که از قبل در ربات بود و در کانال هم منتشر شده بود «منتشرشده» می‌شود.

**دسته‌بندی:** سبک/حال‌وهوا/زبان فقط وقتی از هشتگ یا عنوان حدس زده می‌شود که نام دسته‌ی دقیق و بدون ابهام باشد (مثل #پاپ یا #غمگین)؛ در غیر این صورت خالی می‌ماند. برای تکمیل: 📚 آرشیو ← «🏷 منتشرشده‌های بدون زبان»؛ روی کارت آهنگ، بعد از تعیین زبان/سبک یک خواننده، دکمه‌ی «اعمال برای N آهنگ دیگر این خواننده» و «⏭ بعدی بدون زبان» کار را سریع می‌کند (فقط مقدار خالی را پر می‌کند و چیزی را بازنویسی نمی‌کند).

**محدودیت‌ها:** پست‌های غیرصوتی و پاک‌شده رد می‌شوند. هش محتوا برای آهنگ‌های واردشده محاسبه نمی‌شود (دانلود ۲۰۰۰ فایل)؛ تکراری‌ها فقط با File Unique ID و تشخیص «نام+خوانندهٔ مشابه» گرفته می‌شوند.

## آمار و تحلیل، ابزارهای رشد (مرحله ۵)
**مسیر:** 📊 آمار و تحلیل کانال.
- اعضای کانال (عکس روزانه خودکار + تغییر ۷ و ۳۰ روز)، آمار آرشیو، کاربران، پسندها.
- تعامل داخل ربات (ورود، جست‌وجو، دیدن آهنگ، پسند، پیشنهاد، درخواست، دریافت فایل، خرید) به‌صورت **شمارنده‌ی روزانه‌ی بدون هویت**.
- پست‌های پرواکنشِ کانال (تلگرام واکنش‌ها را به ربات ادمین می‌دهد؛ فقط از لحظه‌ی روشن‌شدن این نسخه شمرده می‌شود).
- 🚀 ابزارهای رشد: نکات مبتنی بر قانون (نه AI) از وضعیت واقعی شما، متن آماده‌ی پست معرفی ربات (برای کپی و پین دستی)، 📈 نمودار رشد اعضا.
- 🗓 گزارش هفتگی (پیش‌فرض خاموش): شنبه‌ها بعد از ساعت ۹ به چت خودتان.

**محدودیت تلگرام:** بازدید (View) پست‌های کانال را ربات‌ها نمی‌بینند؛ از آمار خود کانال (Statistics در تلگرام) استفاده کنید.

## تبلیغات و همکاری با کانال‌ها
**مسیر:** 📢 تبلیغات و درآمدزایی.
- **📢 تبلیغ‌ها:** ساخت تبلیغ (عنوان/شریک، لینک، مبلغ، یادداشت، متن پست، دکمه‌ی «متن | لینک»، شروع/پایان). انتشار پست تبلیغی با همان مسیر امن آهنگ‌ها: پیش‌نمایش ← تأیید ← «بله، همین حالا». محتوا به اثر انگشت گره خورده و بعد از پیش‌نمایش قابل تغییر نیست.
- در لحظه‌ی انتشار تعداد اعضا ثبت می‌شود؛ با «پایان و ثبت نتیجه» افزایش اعضا محاسبه می‌شود. در زمان پایان فقط **یادآوری** می‌گیرید (ربات هیچ پستی را حذف یا منتشر نمی‌کند؛ پست تبلیغ را خودتان حذف کنید).
- **🤝 همکاری‌ها:** ثبت تبادل/معرفی با کانال‌های دیگر، شروع (ثبت اعضا) و پایان (نتیجه).
- 💰 گزارش درآمد: جمع مبلغ تبلیغ‌ها (عددی که خودتان وارد کرده‌اید) + درآمد استارز.

## اشتراک ویژه و درآمدزایی (Telegram Stars)
**مسیر:** 📢 تبلیغات و درآمدزایی ← ⭐ اشتراک ویژه. **پیش‌فرض خاموش.**
- پرداخت داخل خود تلگرام با Stars (XTR)؛ نیاز به درگاه بیرونی یا BotFather Payments نیست. قیمت (استارز)، مدت (روز) و متن پشتیبانی را شما تعیین می‌کنید؛ روشن‌کردن با تأیید.
- **مزایای مشترک:** 📥 دریافت فایل آهنگ داخل ربات (فقط به چت خودش، با `protect_content`)، ⭐ پلی‌لیست‌های ویژه (در پنل پلی‌لیست «⭐ ویژه» را بزنید)، 🎤 ۱۰ درخواست آهنگ در روز.
- ایمنی پرداخت: صورت‌حساب به کاربر، مبلغ و قیمت گره خورده؛ پرداخت تکراری دوباره تمدید نمی‌شود؛ هر پرداخت ثبت می‌شود.
- شما: لیست پرداخت‌ها، **بازپرداخت** با تأیید، اهدای ۳۰ روز اشتراک یا لغو اشتراک از پنل کاربر.
- /terms و /paysupport (الزام تلگرام برای ربات‌های دارای پرداخت) آماده است؛ متن پشتیبانی را در تنظیمات اشتراک وارد کنید.
- برداشت استارز و شرایط آن را در خود تلگرام (Fragment) ببینید. مسئولیت حقوق آهنگ‌هایی که ارائه می‌کنید با شماست.

## 👁 فعالیت کاربران در ربات (با رضایت جداگانه)
تلگرام **به هیچ ربات یا مدیری نمی‌گوید چه کسی داخل کانال پستی را دیده یا آهنگی را پخش کرده**؛ فقط شمارنده‌ی ناشناس بازدید در خود برنامه‌ی تلگرام هست. چیزی که ربات می‌تواند ببیند، **کارهای داخل خود ربات** است.
- کاربر در «⚙️ علایق من» گزینه‌ی «👁 نمایش فعالیت من به مدیر» را دارد (**پیش‌فرض خاموش**، نیازمند رضایت پایه‌ی ثبت اطلاعات). با روشن‌کردن، باز کردن/پسندیدن/دریافت آهنگ در ربات ثبت می‌شود. با خاموش‌کردن همه‌ی سابقه‌اش فوراً پاک می‌شود؛ «حذف اطلاعات من» هم آن را پاک می‌کند. سابقه ۹۰ روز نگه داشته می‌شود. متن «حریم خصوصی» این را اعلام می‌کند.
- مدیر: 👥 کاربران ← «👁 فعالیت آهنگ‌ها»: فهرست آهنگ‌ها با تعداد بازدیدکننده/پسند/دریافت و با زدن هر آهنگ، **نام و نام‌کاربری فقط کسانی که اجازه داده‌اند**. فقط ADMIN_USER_ID.
- نمی‌داند: چه کسی در کانال چه چیزی را دید/پخش کرد؛ و چه کسی از کدام پست کانال آمده (دکمه‌ی زیر پست لینک عمومی ربات است).

## هوش مصنوعی (Claude)
**پیش‌فرض خاموش و رایگان** (قالب و قوانین؛ در پنل صراحتاً «هوش مصنوعی واقعی نیست» نوشته می‌شود).

**فعال‌سازی:**
1. از [console.anthropic.com](https://console.anthropic.com) کلید API بگیرید و حساب را شارژ کنید (پولی است).
2. نصب بسته **اختیاری** است: اگر `anthropic` (SDK رسمی) نصب باشد از آن استفاده می‌شود؛ وگرنه ربات خودش با `httpx` (که از قبل دارد) مستقیم به API وصل می‌شود. (`pip install -r requirements-ai.txt` برای نصب SDK)
3. در `.env`: `AI_PROVIDER=claude` و `ANTHROPIC_API_KEY=...` (کلید را در چت یا جایی دیگر منتشر نکنید). اختیاری: `AI_MODEL=claude-haiku-5-5`.
4. ربات را دوباره اجرا کنید؛ 🤖 وضعیت هوش مصنوعی ← «🧪 آزمایش اتصال».

**مدل و هزینه:** پیش‌فرض `claude-opus-5-5` (قوی‌ترین؛ حدود ۴ و ۲۰ دلار به ازای هر میلیون توکن ورودی/خروجی). برای کارهای ساده‌ی ربات `claude-haiku-5-5` (حدود ۰٫۱ و ۰٫۵ دلار) هم معمولاً کافی است و حدود ۴۰ برابر ارزان‌تر. انتخاب با شماست (`AI_MODEL`). پنل مصرف توکن و هزینه‌ی تخمینی را نشان می‌دهد.

**کجا استفاده می‌شود:**
- ✍️ **کپشن و هشتگ:** نام آهنگ و خواننده را خود برنامه می‌نویسد؛ AI فقط ۱ تا ۲ خط توصیفی و هشتگ می‌دهد (دستور صریح: چیزی از خودت نساز؛ لینک و @آیدی پاک می‌شود). همچنان پیش‌نمایش و تأیید شما لازم است. سقف روزانه‌ی تماس (پیش‌فرض ۱۰۰) قابل تنظیم است.
- 🏷 **دسته‌بندی آرشیو:** 🤖 وضعیت هوش مصنوعی ← «دسته‌بندی با AI». دسته‌ای (۲۵ آهنگ در هر درخواست)، فقط فیلدهای **خالیِ** زبان/سبک/حال‌وهوا و فقط با **اطمینان بالا** پر می‌شود، بازنویسی نمی‌کند، قبل از شروع هزینه‌ی تقریبی را می‌گوید و تأیید می‌گیرد، قابل توقف و ادامه است. دقت AI کامل نیست؛ از کارت آهنگ قابل اصلاح است.
- هر خطا، امتناع مدل، قطع ارتباط یا رسیدن به سقف ← بی‌صدا به کپشن قالبی برمی‌گردد.
- شناسایی آهنگ از روی صدا (Shazam‌مانند) کار مدل متنی نیست و در آینده با سرویس تخصصی اضافه می‌شود.

**Termux (گوشی):** نیازی به نصب `anthropic` نیست و نباید نصبش کنید (به Rust نیاز دارد و روی گوشی شکست می‌خورد). اتصال مستقیم HTTP کار می‌کند و در 🤖 وضعیت هوش مصنوعی می‌نویسد «از اتصال مستقیم HTTP استفاده می‌شود».

## انتقال به سرور
1. یک VPS کوچک لینوکسی (Ubuntu) کافی است. (هزینه میزبانی احتمالی؛ خود Bot API رایگان است.)
2. پروژه را کپی کنید (بدون `.env` و `data/`)، سپس روی سرور همان مراحل راه‌اندازی را انجام دهید و `.env` را دستی بسازید.
3. برای اجرای شبانه‌روزی، نمونه‌ی آماده در `deploy/musicbot.service` هست (یا فایل زیر):
```ini
[Unit]
Description=Bia2Music bot
After=network-online.target

[Service]
WorkingDirectory=/opt/ai-music-manager
ExecStart=/opt/ai-music-manager/.venv/bin/python -m musicbot
Restart=always
RestartSec=5
User=musicbot

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable --now musicbot
sudo journalctl -u musicbot -f
```
4. برای انتقال داده‌ها فایل `data/musicbot.sqlite3` را کپی کنید. **فقط یک نسخه از ربات باید همزمان اجرا باشد** (قبل از روشن‌کردن روی سرور، نسخه کامپیوتر را متوقف کنید).
5. برای رشد زیاد، `db/` را روی PostgreSQL منتقل کنید (SQL فقط در `repositories.py` و `schema.py` است) و در صورت نیاز Webhook به‌جای Long Polling.
